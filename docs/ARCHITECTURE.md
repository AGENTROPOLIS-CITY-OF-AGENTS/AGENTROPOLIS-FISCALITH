# FISCALITH Architecture

FISCALITH is the provider-neutral financial language for autonomous agents and institutional agentic commerce.

```text
AGENTENTITY
  -> ATRALITH / ATG
  -> FISCALITH payload
  -> Execution Envelope
  -> AEGIS
  -> 54T trust enforcement
  -> AQUADUCT when proving/certification is required
  -> PAYRAIL when production routing is approved
  -> provider / rail / contract
  -> financial proof + receipt
  -> FISCALITH result
  -> ATG response
```

FISCALITH does not grant authority, choose a settlement rail, expose secrets, or own custody.

## Semantic families

PAY, SEND, QUOTE, BID, OFFER, INVOICE, ESCROW, JOB, PAYROLL, ROYALTY, SPLIT, BUDGET, TREASURY, FX, CREDIT, COLLATERAL, BRIDGE, SWAP, UNIFIED_BALANCE, ONRAMP, EARN, REFUND, RECONCILE and SETTLE.

## Standing rule

> ATRALITH is the agent language. FISCALITH is the financial language.
